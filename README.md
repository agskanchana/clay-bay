# Clay Bay

A playable preview of Clay Bay, a maths app for children aged 3 to 10: clay friends, today's road of five stops,
the Hatch, Roll-a-Giant, the dress-up and the Critter Garden.

Play it: https://agskanchana.github.io/clay-bay/ (best on a tablet held sideways, or a laptop).

This repository holds only the built app.
